Java：类加载、反射、SPI、动态代理与模块化

发表于2025-09-02|更新于2026-08-13|Java
|总字数:1.3k|阅读时长:4分钟|浏览量:

类加载问题本质是“哪个类、由谁加载”

同名类被不同 ClassLoader 加载后，在 JVM 看来是不同类型。排查 ClassCastException、NoSuchMethodError、SPI 实现找不到、容器插件隔离问题时，必须同时看类全名和 ClassLoader，不能只看 Maven 依赖树。

类的完整生命周期可概括为：加载、连接（验证、准备、解析）、初始化、使用、卸载。准备阶段给静态字段分配内存并赋默认值；初始化阶段才执行静态变量赋值和静态代码块。new、访问非编译期常量静态字段、反射主动使用、启动类等会触发初始化。

双亲委派与自定义加载

常规类加载器按“先委派父加载器，父找不到再自己尝试”的方式加载。它的主要价值是保证核心类唯一，例如避免业务 jar 自己定义 java.lang.String 替代 JDK String，并减少重复加载。

加载器 典型职责
Bootstrap ClassLoader 加载 JDK 核心类，Java 层通常显示为 null
Platform ClassLoader 加载平台模块类
Application ClassLoader 加载应用 classpath 中的业务和依赖类
自定义 ClassLoader 插件、热部署、脚本、隔离运行环境

“双亲委派”不是所有框架绝对遵守的规则。JDBC、SPI、应用服务器等常使用线程上下文类加载器（TCCL）实现父加载器可见 API、子加载器可见实现的反向委派。自定义加载器应优先重写 findClass，谨慎重写 loadClass；若破坏委派模型，需要明确白名单、隔离边界和安全风险。

反射、MethodHandle 与动态代理

反射允许运行时查看类、构造对象、访问字段和调用方法。它适合框架、序列化、ORM、DI 等需要动态适配类型的场景，但业务热路径不应无节制反射。反射性能开销不只在调用本身，还包括查找、访问检查、装箱、异常包装；缓存 Method/构造器并避免重复扫描。

JDK 动态代理基于接口生成代理类，调用进入 InvocationHandler；CGLIB 通过生成目标类子类实现代理。Spring AOP 常用二者，因此 final 类/方法、private 方法和对象内部自调用存在代理边界限制。

MethodHandle 是更底层、可组合的动态调用能力，适合高性能框架或语言运行时；普通业务不需要为了“性能”替换清晰的直接调用。

SPI 与 ServiceLoader

SPI（Service Provider Interface）将接口定义与实现解耦。JDK ServiceLoader 读取 META-INF/services/接口全限定名 文件，按文件中的实现类名加载提供者。典型例子包括 JDBC Driver、日志实现和扩展插件。

SPI 的生产问题通常是：实现 jar 没打进包、shade 合并时覆盖了服务文件、TCCL 不正确、实现构造失败、多个实现顺序不确定。对关键扩展要显式选择 provider、记录实际加载实现，并为插件版本建立兼容契约，不能只依赖类路径碰巧存在。

JDK 9+ 模块化与升级风险

JPMS 使用 module-info.java 声明 requires、exports、opens。exports 允许其他模块编译/访问 public API，opens 主要允许深度反射。JDK 17/21 对 JDK 内部 API 和反射封装更严格，旧框架可能出现 InaccessibleObjectException。

迁移时优先升级框架和依赖，不要长期依赖 --add-opens 绕过封装。临时参数可用于过渡，但应记录模块、包、调用依赖和移除计划。容器镜像需同时验证 JDK 版本、TLS 默认策略、字符集、时区、垃圾收集器与 agent 兼容性。

类冲突与排查

异常/现象 常见根因 排查方法
ClassNotFoundException jar 缺失、类加载器不可见 查看运行时 classpath、打包内容和 ClassLoader
NoSuchMethodError 编译期与运行期依赖版本不一致 dependency:tree、jar 中实际类版本、锁定 BOM
ClassCastException: X cannot be cast to X 同名类被不同 ClassLoader 加载 打印 obj.getClass().getClassLoader()，检查插件隔离
ServiceConfigurationError SPI 文件/实现错误或加载器不对 检查 META-INF/services、TCCL、构造异常
Metaspace 持续增长 热部署/插件 ClassLoader 未释放 Heap Dump 查看 ClassLoader 引用链，关闭线程和 ThreadLocal

高频面试题

问题 回答要点
双亲委派解决什么？ 核心类唯一性、安全性和避免重复加载；框架可在受控场景使用 TCCL 打破单向可见性。
类什么时候初始化？ 主动使用时，如 new、访问非常量静态字段、反射；加载不等于初始化。
为什么 X cannot be cast to X？ 类名相同但 ClassLoader 不同，JVM 视为不同类型。
JDK 动态代理和 CGLIB 区别？ 前者基于接口，后者基于子类；都受代理边界限制。
SPI 有什么风险？ 实现发现依赖 classpath/加载器，版本冲突、实现顺序和打包合并都需治理。
