Java 业务场景

业务场景部分按企业系统常见能力域整理，适合从“会用技术”进一步复习到“能设计生产系统”。

核心交易链路

  • Java面试要点：电商交易场景下单、支付、退款、库存扣减与订单状态流转
  • Java面试要点：支付回调、退款、对账、分账与资金流水
  • Java面试要点：库存中心可售库存、锁定库存、实际库存、流水与回滚
  • Java面试要点：未登录购物车、登录合并、Redis存储与商品失效

营销活动与用户增长

  • Java面试要点：活动预热、限流、排队、库存预扣与防超卖
  • Java面试要点：优惠券领取、核销、过期、叠加规则与防薅羊毛
  • Java面试要点：积分发放、冻结、扣减、过期与流水幂等

安全治理与访问控制

  • Java面试要点：登录、Token、RBAC权限模型与风控
  • Java面试要点：频率限制、设备指纹、黑名单与规则引擎
  • Java面试要点：API网关鉴权、限流、路由、熔断、签名验签与流量治理
  • Java面试要点：操作日志、数据变更日志、敏感操作追踪与归档

分布式系统与平台能力

  • Java面试要点：MQ异步解耦、重试、死信与消费幂等
  • Java面试要点：热点数据、缓存一致性与抗压设计
  • Java面试要点：分布式锁、事务一致性与最终一致性
  • Java面试要点：动态配置、灰度规则、版本回滚与开关治理
  • Java面试要点：多租户 SaaS 租户隔离、数据隔离、配置隔离与套餐限制

数据流转与运营系统

  • Java面试要点：ES检索、筛选、排序、高亮与分页
  • Java面试要点：Excel导入校验、大批量处理与异步导出
  • Java面试要点：定时任务、防重、分布式调度与补偿
  • Java面试要点：日活、订单统计、预计算与实时汇总
  • Java面试要点：库表同步、Binlog、MQ同步、补偿与一致性校验

企业应用与内容平台

  • Java面试要点：审批流、状态机、节点流转与撤回
  • Java面试要点：分片上传、秒传、断点续传、预览与权限控制
  • Java面试要点：短信、邮件、站内信、App Push与多渠道降级
  • Java面试要点：敏感词过滤、机器审核、人工审核与内容状态流转

Java 故障排查

故障排查部分按生产问题类型整理，适合复习线上问题定位、快速止血、根因分析和长期治理。

  • Java面试要点：接口变慢、链路追踪、慢SQL与性能瓶颈定位
  • Java面试要点：CPU飙高、线程栈分析与死循环定位
  • Java面试要点：内存溢出、堆Dump、GC日志与对象泄漏分析
  • Java面试要点：Full GC频繁、服务卡顿与JDK 8、17、21 GC调优
  • Java面试要点：数据库连接池耗尽、慢事务与连接泄漏
  • Java面试要点：Redis热Key、大Key、缓存击穿与缓存雪崩
  • Java面试要点：MQ消息积压、重复消费、死信队列与重试风暴
  • Java面试要点：线程池打满、任务堆积、拒绝策略与参数调优
  • Java面试要点：数据不一致、分布式事务、补偿任务与对账修复
  • Java面试要点：发布后故障、灰度回滚、配置变更与快速止血

使用方式

建议先按目录快速扫一遍，建立“基础技术 -> 中间件 -> 业务场景 -> 故障排查”的知识地图，再回到具体文章做专题复习。业务场景类文章重点关注状态流转、幂等、并发控制、补偿机制和数据一致性；故障排查类文章重点关注现象判断、证据链、快速止血、根因定位和长期治理。
